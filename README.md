# TypeScript Real-Time Chat App

**Name:** John Lloyd T. Bollido  
**Section:** BSIT2A  

## What the Project Does
A real-time chat application built with **TypeScript**, **Express**, and **Socket.IO** (based on the Simplilearn SkillUp TypeScript course project). Users can type and send messages in real time and see incoming messages appear immediately in the chat box, supported by explicit TypeScript interfaces for messages and Socket.IO events.

## Bonus Feature
Added automatic **message timestamps** (`HH:MM`) to the `ChatMessage` interface on the server and displayed each timestamp beside the message in the client UI.
